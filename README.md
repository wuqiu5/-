# 魔塔游戏 (Magic Tower)

一个基于 **C++** 和 **EasyX** 图形库开发的经典魔塔小游戏，作为《数据结构》课程设计的项目。

## 📖 项目简介

本项目实现了经典魔塔游戏的核心玩法。玩家需要在地图中探索、击败怪物、获取道具、提升等级，并逐层向上挑战，最终救出公主（或达成通关条件）。

游戏采用图形化界面，包含地图渲染、角色移动、战斗系统、经验升级、楼层切换等完整功能。

## 🎮 功能特性

- **多楼层地图探索**：支持在多个楼层之间上下切换
- **角色移动与碰撞检测**：基于二维数组的地图碰撞判定
- **怪物战斗系统**：与不同怪物战斗，扣除相应生命值
- **经验值与升级机制**：击败怪物获得经验，满级后自动升级并提升属性
- **楼梯与道具交互**：踩到楼梯可上下楼，拾取道具增强能力
- **图形化界面**：使用 EasyX 绘制地图、角色、怪物及 UI 信息
- **音效播放**：使用 Windows 多媒体接口播放背景音乐

## 🚀 如何运行

### 1. 环境准备

- 安装 **Visual Studio 2022**（需勾选「使用 C++ 的桌面开发」工作负载）
- 下载并安装 **EasyX** 图形库：https://easyx.cn/

### 2. 获取项目

在命令行中执行：

git clone https://github.com/wuqiu5/Project2.git

或者直接在 GitHub 页面点击 **Code → Download ZIP** 下载压缩包。

### 3. 配置 EasyX

由于我的是2022版本需手动安装EasyX 把后缀改为.7z解压。在目录下找到include文件夹复制graphics.h、easyx.h。
切换到魔塔游戏的视图中即在 Visual Studio 中打开 Project2.sln，然后：

1. 右键项目 Project2 → 属性
2. 配置属性 → VC++ 目录 → 包含目录：添加 EasyX 的 include 路径
3. 配置属性 → VC++ 目录 → 库目录：添加 EasyX 的 lib\VC2015\x64 路径
4. 配置属性 → 高级 → 字符集：改为「使用多字节字符集」

### 4. 编译运行

属性页的「配置 + 平台」必须与顶部工具栏一致
- 确保顶部工具栏选择的是 Release | x64（或 Debug | x64）
- 按 F5 或 Ctrl + F5 编译并运行

## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| ↑ / W | 向上移动 |
| ↓ / S | 向下移动 |
| ← / A | 向左移动 |
| → / D | 向右移动 |
| Q | 查看怪物图鉴 |

> 移动时如果前方是怪物则自动进入战斗；如果前方是楼梯则切换楼层；如果前方是道具则自动拾取。

## 🧠 核心实现思路

- **地图存储**：使用三维数组 map[7][13][13] 存储 7 层楼、每层 13×13 的地图数据
- **当前状态**：使用 currentMap、currentLayer 记录当前楼层地图与层数
- **角色属性**：使用 count 记录经验值，升级经验[3] 存储升级所需经验
- **存档功能**：使用 savedMap 保存地图状态，stairsPositions 记录楼梯坐标
